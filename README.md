# Atividade Avaliativa – Estruturas de Dados II
Investigação experimental do comportamento de arrays, matrizes, algoritmos de ordenação e busca.

## Sobre o Projeto
Este repositório contém a resolução da atividade avaliativa focada na análise de complexidade computacional, contagem de operações e implementação prática de:
- Bubble Sort vs. Quick Sort
- Busca Sequencial em Matrizes
- Manipulação e análise de Arrays (Temperaturas)
- Manipulação e análise de Matrizes (Monitoramento de Sensores)

---

## Estrutura de Arquivos
- `ExperimentoDeOrdenacao.py` - Script de testes e comparação entre Bubble Sort e Quick Sort.
- `BuscaMatrizes.py` - Implementação da busca sequencial em matrizes.
- `InvestigacaoArray.py` - Análise estatística de um array de temperaturas.
- `Sensores.py` - Monitoramento bidimensional de sensores.
