# Análise das questões
* **a) Quantas operações de percurso do array foram necessárias?**

```
Foram realizados 2 percursos completos pelo array, resultando em 20 acessos aos elementos no total
(o primeiro para calcular a soma, o maior e o menor valor, e o segundo para contar quantos elementos estavam acima da média).

```

* **b) Qual a complexidade do algoritmo desenvolvido?**

```
A complexidade de tempo é linear, pois o algoritmo percorre o array um número constante de vezes, de modo que o tempo de
execução cresce proporcionalmente ao tamanho da entrada. A complexidade de espaço também é linear para
armazenar os dados no array.

```
